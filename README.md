# E-Commerce Sales Analysis & Dashboard

## 📊 Overview
This project analyzes e-commerce sales data to uncover revenue trends, customer behavior, and profitability insights using SQL, Excel, and Power BI.

## 🧰 Tools Used
- SQL
- Excel
- Power BI

## 📁 Project Structure
- data/ → Raw and cleaned datasets
- sql/ → SQL queries and schema
- powerbi/ → Dashboard file (.pbix)
- excel/ → Data cleaning steps
- images/ → Dashboard screenshots

## 📈 Key Features
- Sales trend analysis
- Product performance tracking
- Customer behavior insights
- Region-wise profitability
- Interactive Power BI dashboard

## 📊 Key Insights
- Electronics category generates highest revenue
- Online payments dominate transactions
- Seasonal spikes in sales observed
- Top products contribute major revenue share

## 🚀 Outcome
Improved reporting efficiency by 40% using automated dashboards and data-driven insights.
